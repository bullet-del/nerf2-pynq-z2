真实测量 Tx 盲测

候选池随场景切换为该场景的全部 held-out test 坐标。训练点不进入正式盲测，避免把训练记忆误当泛化能力。

随机种子的作用：系统把“种子 + 场景 + Tx + bitstream 哈希 + 运行时模型哈希 + 抽查数量”按公开格式输入 SHA-256 计数器算法，现场确定要重算的射线位置。结果页会列出每条射线的完整图 Q15、现场重算 Q15、差值和 ARM Q15，并由电脑端独立复算选点；只要一项不一致，本次运行立即判失败。

时间口径：ARM只计算8/16/32条抽中射线，用于独立正确性复核；FPGA会通过正式生产包重算这些位置所在的数千至数万条射线。结果页会按实际射线数换算每条耗时、吞吐率和归一化加速比，不能直接用两项总秒数判断谁更快。

未连接显示器时请保持不勾选。浏览器仍会显示并保存同一张 GT / PC / FPGA 高清对比图；物理 HDMI 画面不再显示底部色条。4:3校正会在发送前纵向预压缩，抵消显示器拉伸，使三幅极坐标图在屏幕上恢复为圆形。

任意 Tx 连续查询

评委在当前场景边界内输入连续坐标。PC 与 FPGA 预测同一空间谱；此模式只比较二者，不虚构 GT。

固定 Rx 坐标：按场景加载。自由查询超出以上 Tx 范围时会在电脑端和板端同时拒绝。

随机复核：与盲测页使用同一套公开 SHA-256 选点规范。随机种子可以填写评委现场任意给出的 1–64 个可打印字符；它只决定抽查位置，不改变预测图。

ARM与FPGA计时：ARM时间只覆盖少量抽中射线；FPGA复核时间覆盖抽中位置所在的完整生产包。页面按工作量归一化后展示吞吐率，ARM稀疏复核时间不代表ARM生成完整90×360空间谱的时间。

未连接显示器时请保持不勾选。浏览器仍会显示并保存 PC / FPGA 高清对比图；物理 HDMI 不显示底部色条，并按所选显示器比例保证圆形。
