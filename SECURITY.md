# Security and responsible disclosure

This repository controls a local development board and opens local HTTP
services for demonstrations. Bind those services only to trusted laboratory
networks. Do not expose the PYNQ service directly to the public Internet.

Before reporting a defect, preserve the failing command, package hashes,
software versions, and the smallest non-sensitive log that reproduces it.
Remove personal paths, IP addresses, Wi-Fi credentials, and unpublished data.

For a published Git host, use its private security-advisory channel. For an
offline competition copy, report the issue directly to the project team.
