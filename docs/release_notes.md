# Stage39 complete engineering submission

This release accompanies the full current repository tree and MIT license.
The design report is the exact submitted AMD report, including its LLM
collaboration appendix.

The current main branch also includes `report/llm_collaboration.md`, containing
the initial Stage plan and actual debugging exchanges with verification evidence.

Six assets provide original reproduction inputs, the matched archived PYNQ/PC
deployments, all 1725 physical FPGA output maps, raw power measurement evidence
and the final demonstration video. Asset descriptions, sizes and direct links
are listed in `data/downloads.json` in the source tree.

The repository contains the RTL/Tcl, Python and PYNQ source, both competition
Skills, actual simulation logs, original resource/timing reports, deployed
BIT/HWH, full per-map comparisons and physical finalization results.

The existing physical archive belongs to the matched October 8/9 deployment.
The October 13 cold-reproduction PASS covers the separately reconstructed
software/RTL/Vivado pipeline. New builds need their own physical execution.
